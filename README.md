# Silmara Advocacia — Site Oficial

Site moderno e responsivo para o escritório **Silmara Advocacia**.

## 🚀 Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/silmara-advocacia.git
   ```
2. Abra o arquivo `index.html` no navegador — funciona sem servidor.

## 📁 Estrutura

```
silmara-advocacia/
├── index.html   # Site completo (HTML + CSS + JS inline)
└── README.md    # Este arquivo
```

## 🌐 Deploy no GitHub Pages

1. Vá em **Settings → Pages**
2. Source: `main` branch, pasta `/root`
3. Salve — o site ficará online em `https://seu-usuario.github.io/silmara-advocacia`

## ✏️ Personalizar

Abra o `index.html` e substitua:
- `(11) 98765-4321` → telefone real
- `contato@silmaraadvocacia.com.br` → e-mail real
- `OAB/SP 123.456` → número OAB real
- `Av. Paulista, 1578 — Sala 810` → endereço real
- `https://wa.me/5511987654321` → número WhatsApp real (formato: 55 + DDD + número)

## 🛠 Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Google Fonts (Cormorant Garamond + Inter)
- Canvas API para partículas animadas
- Intersection Observer para animações de scroll
